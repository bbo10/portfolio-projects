## 핵심 코드

**1. 이동비를 돈으로 바꾸기** (셀 107, 핵심만 줄여서 옮김)
직선거리에 실제 경로 보정 계수 1.3을 곱하고, 왕복 거리의 기름값을 주유비에 더합니다. 보정 계수는 주요 지점 5곳의 실제 경로 비교에서 하위 25% 값을 골라 보수적으로 잡았습니다.

```python
df['distance_km'] = haversine(origin, station) * 1.3
df['detour_cost'] = (df['distance_km'] * 2 / efficiency) * df['price']
df['net_total_cost'] = df['price'] * amount + df['detour_cost'] - df['total_benefit']
```

**2. 손익분기 기준 만들기** (셀 117)
더 가는 거리만큼의 왕복 기름값을 주유량으로 나누면 "리터당 최소 얼마가 싸야 하는지"가 나옵니다. 평균가 1,702원, 연비 15km/L, 50L 기준으로 편도 1km당 4.5원입니다.

detour_cost = (dist * 2) / efficiency * avg_price

## 데이터를 직접 만들며 해결한 문제

- **반경 검색 0건:** 격자 좌표마다 Opinet 반경 검색을 호출했지만 결과가 0건이었습니다. 그래서 지도 데이터를 먼저 모으고 공공 데이터를 붙이는 방식으로 바꿨습니다.
- **좌표 약 149km 오차:** Opinet 좌표를 표준 KATEC로 변환하면 위치가 크게 어긋났습니다. 데이터 자체가 비표준이라고 판단해, 위치를 아는 주유소 한 곳으로 오프셋을 구해 보정했고 오차가 0.05m로 줄었습니다. (보정 계산은 이 노트북에 포함되어 있지 않습니다.)
